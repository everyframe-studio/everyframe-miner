# everycli v0.7.3

Ideogram Vector adds editable SVG generation through your Fal API key. Choose low, medium or high quality and use up to five reference images. Each job returns one SVG; quality and references are included in its price.

Update with `everycli update`. Install the compatible worker using `everycli worker-update`, or let enrolled automatic updates install it when idle. After fresh attestation, set a discount for **Ideogram Vector** in All models. Existing model bids stay unchanged.

The model ID is `studio/media/fal/ideogram/vector/text-to-vector`. It uses `FAL_KEY`, a maximum combined prompt of 9,500 characters, and reference images up to 10 MB each.
