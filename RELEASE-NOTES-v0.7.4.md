# everycli v0.7.4

Kling 4.0, HeyGen Video, Gemini Omni Flash 1.1, and Vidu Q4 Preview join the miner model catalog. All four use your existing Fal key.

Kling 4.0 is available through the Fal worker adapter: 3–30 seconds, 720p or
1080p, text prompts, first/last frames, and image/video references. Reference
video pricing includes the provider’s minimum billable duration.

Run `everycli update` and `everycli worker-update`, or let enrolled automatic
worker updates install the signed package when idle. After fresh attestation,
select **Kling 4.0** in **All models** and set its discount. Existing bids stay
unchanged. It uses your existing `FAL_KEY`; no direct Kling key is needed.

See [supported formats and setup](KLING4.md).

See [all new video formats](VIDEO-MODELS-v0.7.4.md), including Gemini 4K output and Vidu image/voice references.
