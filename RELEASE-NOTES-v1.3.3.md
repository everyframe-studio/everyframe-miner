# everycli v1.3.3

Miners can serve Sand.ai MAGI-2 through Higgsfield. One offer supports text prompts, opening and closing frames, and media references for 4–30 second videos in 1080p with generated audio. Higgsfield permits one active MAGI-2 generation per account.

Run `everycli update`, reopen any running UI, then run `everycli worker-update --check`. To serve MAGI-2, install the offered worker from your existing profile, configure Higgsfield credentials, and enable the MAGI-2 offer in Models.
